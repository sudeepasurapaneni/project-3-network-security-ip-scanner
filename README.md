# Network Security IP Range Scanner

A web-based network security tool designed to scan IP ranges, explore host discovery, and visualize network scanning results. This project provides an interactive dashboard for learning network security concepts and practicing authorized network discovery.

## 🚀 Features

- **IP Range and Subnet Input:** Accepts IP addresses and CIDR notation, such as `192.168.1.0/24`.
- **Host Discovery:** Displays host discovery results and scanning status.
- **Multiple Scanning Modes:** Provides options for ARP/ICMP discovery, TCP probing, and aggressive discovery.
- **Real-Time Dashboard:** Displays scanning progress, status updates, and network activity logs.
- **Host Details:** Presents available information, including IP addresses, response times, MAC addresses, and port details.
- **Network Topology Visualization:** Offers a graphical representation of discovered hosts and gateway information.
- **Export Reports:** Supports exporting scan results in JSON format.
- **Responsive User Interface:** Provides a clean, user-friendly interface for desktop and mobile screens.

## 🛠️ Technologies Used

## ⚙️ Getting Started

### Prerequisites

- A modern web browser.
- A local development environment or web server, depending on the project setup.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/sudeepasurapaneni/project-3-network-security-ip-scanner.git
```

**2. Navigate to the project directory**

```bash
cd project-3-network-security-ip-scanner
```

**3. Launch the project**

Open the main HTML file in your browser or use a local development server appropriate for the project's configuration.
